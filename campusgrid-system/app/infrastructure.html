Technical Spec

Architecture

Edge · Sensors & Hardware
Tags
Passive UHF RFID in student ID
EPC Gen2 / ISO 18000-6C inlay embedded in existing campus card. No battery, no new card issued. Read range ~3 m at doorway.
Readers
Fixed UHF RFID readers
PoE-powered, one per doorway (halls, tutorials, labs, workshops) + secondary checkpoints along main walkways for pace tracking.
Cameras
Ceiling headcount sensors
Low-res wide-angle, doorway-mounted. Lightweight person-count model on edge — transmits count only, never raw video.
Edge compute
Raspberry Pi 4 / Jetson Nano
One board per doorway cluster. Runs headcount model + local MQTT publisher. OS: Raspberry Pi OS or Ubuntu Core.
Backend · Server Layer
Ingestion
MQTT broker (Eclipse Mosquitto)
Thousands of small, frequent publishes from readers — natural fit vs REST polling.
Processing
Stream consumer service
Aggregates taps → per-minute occupancy. Computes walkway pace (time-of-flight between checkpoints). Reconciles RFID count vs camera headcount.
Storage
TimescaleDB + PostgreSQL
Time-series DB for occupancy & pace pings. Relational DB for timetables, attendance, directory, flagged-tag cases.
API
REST / GraphQL app service
Serves mobile app: directory, navigation, attendance, real-time data, sustainability leaderboard. Assistant ETA engine on top.
